STEP 1: Kinematic String Constraint Hover to view String Paths

We trace the length of the string segment dynamically starting from the right wall fixed anchor d:

L = (d - x₂) + 2(x₁ - x₂) + C

Simplifying the formula yields:

L = d + 2x₁ - 3x₂ + C

Since the string length L is non-extensible, its time derivative is zero. Differentiating twice gives:

2a₁ - 3a₂ = 0 ⇒ a₁ = 1.5 a₂
STEP 2: Massless Pulley Tension Mechanics Hover to view Force FBDs

For two massless pulleys (m = 0), the net force acting on each pulley must equal zero at all times:

  • Pulley A: Pulled left by coupler connector T_A and right by two segments of tension T: 2T - T_A = 0 ⇒ T_A = 2T
  • Pulley B: Pulled right by coupler connector T_B and left by two segments of tension T: T_B - 2T = 0 ⇒ T_B = 2T
STEP 3: Coupled Equations of Motion

Applying ΣF = ma to both moving parts:

Block 1: F - T_B = m₁ a₁ ⇒ F - 2T = m₁ a₁
------------------------------
Block 2: T + T_A = m₂ a₂ ⇒ 3T = m₂ a₂

Solve Block 2 for tension T = ⅓ m₂ a₂. Substitute into Block 1's equation:

F - ⅔ m₂ a₂ = m₁ a₁

Now, inject the kinematic constraint a₁ = 1.5 a₂:

F - ⅔ m₂ a₂ = 1.5 m₁ a₂ ⇒ F = (1.5 m₁ + ⅔ m₂) a₂
STEP 4: Closed-Form Algorithm & Integration

The system is simulated using the exact closed-form solution derived algebraically:

a₂ = 6F / (9m₁ + 4m₂)
a₁ = 1.5 · a₂

To compute real-time physics, we execute Euler-Cromer integration at 60 FPS:

v2_new = v2 + a2 * dt; v1_new = 1.5 * v2_new;
x2_new = x2 + v2_new * dt;
x1_new = x1 + v1_new * dt;
