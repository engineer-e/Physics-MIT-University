The Computational Integration Engine

How computers solve differential equations frame-by-frame

Numerical Algorithm

To animate physics in real-time, we cannot rely solely on the symbolic formulas because forces fluctuate with collisions, constraints, limits, and manual user pushes. Instead, the simulator runs a **Numerical Integration Loop** called **Euler-Cromer integration** every single frame ($dt \approx 0.016 \text{ s}$).

JavaScript Engine

Step-by-Step Simulation Loop Routine

// 1. Compute Analytical Accelerations on each tick
const num = (2 * m1 - m2) * g;
const den = 2 * m1 + m2 / 2;
let a1 = num / den;

// Apply drag/damping to replicate air friction
a1 -= damping * v1;

// 2. Enforce constraint condition: a2 = -a1 / 2
let a2 = -a1 / 2;

// 3. Euler-Cromer integration step
v1 += a1 * dt;
v2 += a2 * dt;

y1 += v1 * dt;
y2 += v2 * dt;

// 4. Enforce Boundary Constraints (Rope limits, ceiling blockages)
if (y1 < min_height) {
    y1 = min_height; v1 = 0;
    y2 = max_height; v2 = 0; // Anchored system state
}
