Mathematical & Computational Algorithms

Learn how the physical concept of mass distributions transitions from calculus-based integration to computer-based discretization algorithms.

Mathematical Continuum

To find the total mass $M$ of an object, we sum up all its individual pieces $dm$. As the size of the piece shrinks to zero, the sum becomes a continuous integral:

$M = \int dm$

1. One-Dimensional Distribution (1D):

For an object like a linear rod or wire, the differential element of length is $dl$. This segment contains an infinitesimal mass element $dm$:

$dm = \lambda(x) \, dl \quad \Longrightarrow \quad M = \int_0^L \lambda(x) \, dx$

Where $\lambda(x)$ is the linear mass density (kg/m).

2. Two-Dimensional Distribution (2D):

For a flat plate, we consider an area element $dA$ containing mass $dm$:

$dm = \sigma(x, y) \, dA \quad \Longrightarrow \quad M = \iint \sigma(x, y) \, dA$

Where $\sigma(x, y)$ is the surface mass density (kg/m²).

3. Three-Dimensional Distribution (3D):

For a solid block or cylinder, we write the volume element $dV$ containing mass $dm$. In our simplified block example, we can divide the object into slices of area $A$ and thickness $dx$:

$dV = A \cdot dx \quad \Longrightarrow \quad dm = \rho(x) \, (A \, dx) \quad \Longrightarrow \quad M = \int_0^L \rho(x) \, A \, dx$

Where $\rho(x)$ is the volumetric mass density (kg/m³).

Computational Riemann Algorithm

Computers cannot perform analytical continuous integration directly. Instead, we divide the object into $N$ discrete slices, calculate the mass of each finite piece $\Delta m_i = \rho(x_i) \Delta V_i$, and sum them up.

mass_integration.js Left Riemann Sum 
function integrateMass(N, L, ρ_func, V_func) {
    let totalMass = 0;
    let dx = L / N; // Step size

    for (let i = 0; i < N; i++) {
        // 1. Determine local position
        let xi = i * dx; 
        
        // 2. Compute local density & element size
        let density = ρ_func(xi);
        let dV = V_func(dx, xi);
        
        // 3. Accumulate Δm = ρ(x) * dV
        totalMass += density * dV;
    }
    return totalMass;
}

Convergence Mechanism:

As $N \to \infty$, the step size $\Delta x \to 0$. The difference between the analytical value and the numerical sum (error) scales as $\mathcal{O}(1/N)$ for simple Riemann sums, and can be optimized using the Trapezoidal Rule or Simpson's Rule.
