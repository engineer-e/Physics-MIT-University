The Infinite Tension Paradox

Notice how the tension sky-rockets when you push the angle close to 90° (perfectly straight). It is mathematically impossible to have a perfectly horizontal rope because cos(90°) = 0, meaning an infinite force would be required to support even an extremely light rope!

Numerical Engine (Verlet Chain Relaxer)

While human analysis is neat, a computer models the rope as a continuous elastic catenary. We achieve this using a Verlet Constraint Solver.

// 1. Apply Gravitational Forces
node.pos.y += gravity * dt * dt;
// 2. Relaxation Loop (Distance Constraint Solver)
let dx = p2.x - p1.x, dy = p2.y - p1.y;
let distance = Math.sqrt(dx * dx + dy * dy);
let error = targetLength - distance;
let correction = (error / distance) * 0.5;
p1.subtract(correction); p2.add(correction);
// 3. Calculate Node Tension forces
local_tension = spring_k * error;
