Expert Step-by-Step Computational Derivation

Lecture Synced

Consider two stacked blocks with applied force $F$ on the bottom block $m_1$. We model all physical interactions via Newton's Second Law:

M₂

Top Block $m_2$ (Bound only by Interface Friction):

Normal Force: $N_{\text{inter}} = m_2 \cdot g$

Static friction force required to prevent sliding: $f_s = m_2 \cdot a$

M₁

Bottom Block $m_1$ (Driven by applied force $F$):

Ground Normal Force: $N_{\text{ground}} = (m_1 + m_2) \cdot g$

Kinetic Ground Friction: $f_{k,\text{ground}} = \mu_g \cdot (m_1 + m_2) \cdot g$

When the blocks go together (Unified Motion), their accelerations are the same: $a_1 = a_2 = a$.

The maximum acceleration of Block 2 is bounded by the static friction threshold: $$f_{s,\max} = \mu_s \cdot m_2 \cdot g \implies a_{\max} = \frac{f_{s,\max}}{m_2} = \mu_s \cdot g$$ If the system accelerates faster than $a_{\max}$, the static friction limit is exceeded, and the blocks begin to slip relative to each other.

Substituting this maximum acceleration condition back into our bottom block's equation gives the maximum applied force threshold $F_{\max}$:

Step-by-step substitution:

$$F_{\max} = f_{k,\text{ground}} + f_{s,\max} + m_1 \cdot a_{\max}$$
$$F_{\max} = f_{k,\text{ground}} + f_{s,\max} + m_1 \cdot \left(\frac{f_{s,\max}}{m_2}\right)$$
$$F_{\max} = f_{k,\text{ground}} + f_{s,\max} \left(1 + \frac{m_1}{m_2}\right)$$

To computationally model this dynamic state transition, the simulator implements a Stick-Slip State Machine:

// Check state inside numerical integration loop
if (state === 'unified') {
let total_m = m₁ + m₂;
let accel = (F - f_k,ground) / total_m;
let required_fs = m₂ * accel;
if (Math.abs(required_fs) > f_s_max) {
state = 'slipping'; // Exceeded threshold!
} else {
a₁ = a₂ = accel;
}
} else if (state === 'slipping') {
// Relative slipping uses kinetic friction
let f_kinetic_inter = μk * m₂ * g;
a₂ = f_kinetic_inter / m₂;
a₁ = (F - f_k,ground - f_kinetic_inter) / m₁;
}
