The "Vector Subtraction" Intuition Box

Why does centripetal acceleration point inward? Acceleration is $\lim_{\Delta t \to 0} \frac{\Delta \vec{v}}{\Delta t}$. If we align two consecutive velocity vectors $\vec{v}_1$ and $\vec{v}_2$ tail-to-tail, the change vector $\Delta\vec{v} = \vec{v}_2 - \vec{v}_1$ points directly toward the center of the circle!

💡 The Paradox of Constant Speed Acceleration

In basic linear motion, acceleration indicates an increase or decrease in speed. However, in Uniform Circular Motion (UCM), the speed $v = |\vec{v}|$ is perfectly constant.

"Speed is a scalar, but Velocity is a vector. Acceleration is the change in the Velocity vector."

Because the velocity vector is constantly rotating to stay tangent to the path, its *direction* is changing. This change in direction is what constitutes the acceleration. Since there is no change in speed, there is zero component of acceleration along the path of motion (tangential). Therefore, the acceleration must point perpendicular to the motion: directly inward.

📐 Differentiating Components with Chain Rule

When taking the time derivative of positions like $x(t) = R\cos(\theta(t))$, we must apply the chain rule because the angle $\theta(t)$ changes with time:

$\frac{d}{dt}[ \cos(\theta(t)) ] = -\sin(\theta(t)) \cdot \frac{d\theta}{dt}$

The $\frac{d\theta}{dt}$ factor (denoted as $\omega$) is critical. It scales the magnitude of the velocity vector. If you rotate twice as fast, the angular velocity doubles, meaning the velocity vector doubles and the acceleration vector scales by a factor of four ($\omega^2$)!

💻 Standard Computational Engine Loop

How does a physics engine calculate this step-by-step? In numerical simulators, we compute the kinematics of the system at each frame using the following update logic: 

// 1. Increment current angle over timestep dt
theta += omega * dt;

// 2. Set current position vector components
pos.x = R * cos(theta);
pos.y = R * sin(theta);

// 3. Evaluate analytical vector coordinates
vel.x = -R * omega * sin(theta);
vel.y = R * omega * cos(theta);

acc.x = -R * omega * omega * cos(theta);
acc.y = -R * omega * omega * sin(theta);
