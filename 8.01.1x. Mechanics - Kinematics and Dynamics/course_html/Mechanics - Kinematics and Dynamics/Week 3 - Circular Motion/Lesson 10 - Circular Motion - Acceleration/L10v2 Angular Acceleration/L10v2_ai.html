The Four Sign Permutations Explained

Just like linear kinematics ($v_x$ and $a_x$), circular motion direction and speed trends are defined exclusively by the signs of $\omega_z$ and $\alpha_z$.

Case 1A (Speeding Up CCW) CCW Acceleration
ωz > 0 Positive velocity (CCW)
+
αz > 0 Positive acceleration (CCW)

Both velocity and acceleration vector components act in the Counterclockwise (CCW) direction. Because they share the exact same sign, the rotational velocity becomes increasingly positive, meaning the object speeds up in the CCW direction.

Linear Analogy: vx > 0, ax > 0 (Moving right, speeding up)
Case 1B (Braking CCW) CW Deceleration
ωz > 0 Positive velocity (CCW)
+
αz < 0 Negative acceleration (CW)

The object rotates CCW, but angular acceleration acts in the opposite direction (CW). This creates a torque opposing the motion. The rotation rate slows down continuously, acting like classic mechanical braking.

Linear Analogy: vx > 0, ax < 0 (Moving right, braking)
Case 2A (Braking & Reversing) CCW Pull
ωz < 0 Negative velocity (CW)
+
αz > 0 Positive acceleration (CCW)

The object rotates Clockwise, but acceleration exerts a force in the Counterclockwise direction. The object will rapidly slow down to zero, temporarily stop, then reverse directions to start spinning faster in the positive CCW direction.

Linear Analogy: vx < 0, ax > 0 (Moving left, braking/reversing)
Case 2B (Speeding Up CW) CW Acceleration
ωz < 0 Negative velocity (CW)
+
αz < 0 Negative acceleration (CW)

Both vectors are negative, pointing Clockwise. Because the acceleration has the same directional sense as velocity, the object gets faster and faster in the CW direction, despite both vectors having negative numeric coordinate signs.

Linear Analogy: vx < 0, ax < 0 (Moving left, speeding up)

The Calculus & Dynamic Vectors

For any point mass orbiting on a path of radius r, rotational coordinates map mathematically to Cartesian space. Let us trace the position vector r(t) and its rates of change:

Position Vector
r⃗(t) = r(cos θ)î + r(sin θ)ĵ = r r̂
Angular Velocity
ωz = dθ/dt
→
v⃗t = r ωz θ̂
Angular Accel
αz = dωz/dt = d²θ/dt²
→
a⃗t = r αz θ̂

Total Spatial Acceleration Formula:

Centripetal Term
- r ω² r̂
+
Tangential Term
r αz θ̂
=
Total Acceleration (a⃗)
a⃗c + a⃗t

Note: Centripetal acceleration exists as long as there is angular speed (ω ≠ 0). Tangential acceleration exists if and only if there is angular acceleration (α ≠ 0).

The Computational Loop

Simulators do not run analytic equations continuously. They approximate calculus using step-by-step Euler Integration. Below is the precise numerical algorithm powering this simulator:

JS Engine
// 1. Retrieve Current Step Duration (dt ≈ 0.016s)
let dt = deltaTime / 1000;
// 2. Update Angular Kinematics
omega_z += alpha_z * dt;
theta += omega_z * dt;
// 3. Update Synced Linear Analog
vx += ax * dt;
x += vx * dt;
// 4. Coordinate Transformation to Pixels
const px = cx + r * Math.cos(theta);
const py = cy + r * Math.sin(theta);

Why does Euler Integration work?

By taking small chunks of time dt, we assume the acceleration and velocity are constant during that interval. This lets computers convert complex differential equations into additions.
