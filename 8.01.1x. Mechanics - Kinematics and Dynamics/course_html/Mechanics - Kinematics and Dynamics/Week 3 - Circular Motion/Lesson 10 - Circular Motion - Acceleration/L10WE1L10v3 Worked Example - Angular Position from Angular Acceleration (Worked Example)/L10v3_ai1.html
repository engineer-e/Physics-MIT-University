Mental Model: Linear vs. Circular

One of the main intuitive leaps in physics is seeing that tangential direction in circular motion is mathematically identical to 1-dimensional linear motion.

1D Linear Space
  • Position: x(t)
  • Velocity: vx(t) = dx/dt
  • Acceleration: ax = dv/dt
  • Straight line path.
Tangential Circular Space
  • Arc Length: s(t) = R·θ(t)
  • Tangential Vel: vθ = ds/dt
  • Tangential Accel: aθ = dv/dt
  • Curved circular path.
Critical Intuition Warning: Unlike linear motion, circular motion always contains a second vector component, Radial/Centripetal Acceleration (ar = -v²/R), pointing directly inward to continuously bend the velocity vector, even if tangential acceleration is zero!

Computational Integration Loop (Euler)

When computers solve kinematic systems dynamically, they approximate the integral using tiny time steps (dt). This simulator runs this numerical approximation in parallel.

// Executed every simulation step (dt ≈ 0.016s)

let a_theta = A - B * t;

v_theta += a_theta * dt; // Numerical integral

s += v_theta * dt; // Numerical integral

theta += (v_theta * dt) / R; // Convert to angle

⚠️ Integration Drift Comparison

Notice how numerical values slightly diverge from the exact calculus analytical lines at high speed! This demonstrates why scientists use small time steps (Runge-Kutta) to avoid simulation drift.
