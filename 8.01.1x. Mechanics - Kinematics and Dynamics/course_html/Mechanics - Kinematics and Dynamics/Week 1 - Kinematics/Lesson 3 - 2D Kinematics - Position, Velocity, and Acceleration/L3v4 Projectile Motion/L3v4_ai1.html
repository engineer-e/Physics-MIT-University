x(t)
Horizontal Position (No Forces)
$$x(t) = x_0 + v_{x0}t$$

Since $a_x = 0$, velocity remains constant. The horizontal path increases linearly over time.

y(t)
Vertical Position (Gravity Constant)
$$y(t) = y_0 + v_{y0}t - \frac{1}{2}gt^2$$

Downward acceleration $a_y = -g$ shapes the curve. Position behaves quadratically over time.

y(x)
Path Equation (Time Independent)
$$y(x) = y_0 + \frac{v_{y0}}{v_{x0}}x - \frac{g}{2v_{x0}^2}x^2$$

Formed by substituting $t = x / v_{x0}$. Mathematically proves the trajectory is a clean parabola!

Mathematical Continuum Model

1

Newton's 2nd Law Application ($\Sigma \vec{F} = m \vec{a}$)

Applying vectors on coordinate system unit vectors $\hat{i}$ (horizontal) and $\hat{j}$ (vertical):

Horizontal direction ($\hat{i}$): $$\Sigma F_x = 0 \implies m a_x = 0 \implies a_x = 0$$
Vertical direction ($\hat{j}$): $$\Sigma F_y = -mg \implies m a_y = -mg \implies a_y = -g$$
2

Integration for Kinematics Equations

Integrating acceleration with respect to flight time ($t$):

Velocity Vector Components: $$v_x(t) = v_{x0}$$ $$v_y(t) = v_{y0} - gt$$
Position Vector Components: $$x(t) = x_0 + v_{x0}t$$ $$y(t) = y_0 + v_{y0}t - \frac{1}{2}gt^2$$
3

Derivation of Trajectory Equation (Eliminating Time)

By isolating $t$ from the horizontal position formula, we substitute it into the vertical motion component:

$$t = \frac{x}{v_{x0}}$$
Substituting $t$ into the $y(t)$ quadratic formula:
$$y(x) = y_0 + v_{y0}\left(\frac{x}{v_{x0}}\right) - \frac{1}{2}g\left(\frac{x}{v_{x0}}\right)^2$$
Final Parabolic Trajectory Formula: $$y(x) = y_0 + \frac{v_{y0}}{v_{x0}}x - \frac{g}{2v_{x0}^2}x^2$$

Numerical Computational Steps

Simulators cannot calculate with continuous infinity. Instead, they slice time into microscopic intervals ($\Delta t$) using Euler's integration technique.

NUMERICAL_SOLVER.PY 
# 1. Initialize simulation parameters
g  = 9.81    # m/s^2
dt = 0.010   # Time-step (seconds)

x, y   = 0.0, y0
vx, vy = v0x, v0y
t      = 0.0

# 2. Main execution/simulation loop
while y >= 0.0:
    # Calculate updates
    x  += vx * dt
    vy -= g * dt
    y  += vy * dt
    t  += dt
    
    # Save telemetry for visual plot trails
    record_telemetry(t, x, y, vx, vy)
Continuous vs Numerical: As $\Delta t \to 0$, numerical values converge to exact algebraic trajectories. Try adjusting $\Delta t$ above to notice its sensitivity on calculations.

Lecture Reference Guide

Need a reminder? According to Newton's Second law, there is no acceleration horizontally ($a_x = 0$) because we assume zero air drag.

Vertical acceleration is constant and downward due to gravitational pull ($a_y = -g = -9.8\text{ m/s}^2$).

At the highest vertex of the parabola, vertical velocity is exactly $0$, but the horizontal velocity components remain unchanged.
