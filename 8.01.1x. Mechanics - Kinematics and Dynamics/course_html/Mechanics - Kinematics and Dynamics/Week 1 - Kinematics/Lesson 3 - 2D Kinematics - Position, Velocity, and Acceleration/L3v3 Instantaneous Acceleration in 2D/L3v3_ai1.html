Core Principle

How do we visualize acceleration in two dimensions?

Unlike 1D motion where velocity only changes in magnitude (forward/backward), 2D motion introduces changes in both magnitude and direction. To find the acceleration vector $\vec{a}$, we must perform vector subtraction $\Delta \vec{v} = \vec{v}(t_2) - \vec{v}(t_1)$ by translating both velocity vectors to a common origin to line up their tails.

Computation Infographic & Algorithm

1

Express Velocity as Independent Vector Components

Decompose the 2D velocity vector into $x$ and $y$ dimensions:

$$\vec{v} = v_x \hat{i} + v_y \hat{j} = \frac{dx}{dt} \hat{i} + \frac{dy}{dt} \hat{j}$$
2

Analyze the Velocity Difference ($\Delta \vec{v}$)

Subtract the initial velocity vector from the final velocity vector. Graphically translate the tails to the same origin:

$$\Delta \vec{v} = \vec{v}(t_2) - \vec{v}(t_1)$$
3

Take Limit to Yield Instantaneous Acceleration

Let $\Delta t$ approach $0$. Take the derivatives of each independent vector component:

$$\vec{a}(t) = \lim_{\Delta t \to 0} \frac{\Delta \vec{v}}{\Delta t} = \frac{d\vec{v}}{dt} = \frac{dv_x}{dt}\hat{i} + \frac{dv_y}{dt}\hat{j}$$
4

Obtain Acceleration Magnitude

Calculate the net physical scalar size of the acceleration vector using the Pythagorean theorem:

$$a = |\vec{a}| = \left(a_x^2 + a_y^2\right)^{1/2}$$

Formula Cheat Sheet

Kinematics
X-Velocity Component
$v_x = \frac{dx}{dt}$
Y-Velocity Component
$v_y = \frac{dy}{dt}$
X-Acceleration Component
$a_x = \frac{d^2x}{dt^2}$
Y-Acceleration Component
$a_y = \frac{d^2y}{dt^2}$
