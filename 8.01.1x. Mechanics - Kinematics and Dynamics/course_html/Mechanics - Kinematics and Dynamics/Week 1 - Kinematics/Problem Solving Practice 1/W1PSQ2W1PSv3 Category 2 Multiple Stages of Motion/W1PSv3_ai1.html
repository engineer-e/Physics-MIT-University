P1

Phase 1: Cruising with Constant Speed

Boundary Domain: $0 \le t \le t_1$

In Phase 1, the driver cruises undisturbed. Because velocity is perfectly uniform, there is no change in momentum, hence the net force and acceleration are strictly zero.

1. Acceleration Equation
$$a(t) = 0$$
2. Velocity via Calculus Integration

Integrating acceleration with initial condition $v(0) = v_0$:

$$v(t) - v(0) = \int_0^t a(t') \, dt' = \int_0^t 0 \, dt' \implies v(t) = v_0$$
3. Position via Calculus Integration

Integrating constant velocity with initial condition $x(0) = 0$:

$$x(t) - x(0) = \int_0^t v(t') \, dt' = \int_0^t v_0 \, dt' \implies x(t) = v_0 t$$
P2

Phase 2: Deceleration with Jerk

Boundary Domain: $t_1 \le t \le t_2$

At $t_1$, the brakes are engaged. The deceleration increases linearly over time with a scale factor $c$. This produces a linearly increasing negative acceleration (a constant rate of Jerk $-c$).

1. Linear Deceleration Profile
$$a(t) = -c(t - t_1)$$
2. Velocity Profile via Definite Integration

Integrating with boundary condition $v(t_1) = v_0$:

$$v(t) - v(t_1) = \int_{t_1}^t -c(t' - t_1) \, dt'$$ $$v(t) = v_0 - \frac{1}{2}c(t - t_1)^2$$
3. Position Profile via Integration

Integrating with boundary transition condition $x(t_1) = v_0 t_1$:

$$x(t) - x(t_1) = \int_{t_1}^t \left[v_0 - \frac{1}{2}c(t' - t_1)^2\right] dt'$$ $$x(t) = v_0 t_1 + v_0(t - t_1) - \frac{1}{6}c(t - t_1)^3$$

Sticky Memory Anchors & Sensory Cues

Using visual metaphors and structural triggers to build long-term retention

The Cruise Control Calm

Mental Image: Cruising smoothly over flat glass. No wind resistance, no bumps. You are drifting forward like an ice hockey puck. Since acceleration is dead silent at $a=0$, velocity is frozen at $v_0$. Position strictly accumulates linearly like steps on a conveyor belt: $x(t) = v_0 t$.

The Stop-Line Squeeze

Mental Image: At time $t_1$, you don't instantly lock the tires. You press down the brake pedal deeper and deeper. This is a gradual, crushing squeeze. The force increases smoothly—which is why the deceleration curve slopes down. Because deceleration is dynamic, the velocity doesn't drop as a flat line; it plunges downwards in an increasingly steep quadratic avalanche.

The Kinematic Relay Baton

Mental Image: Two runners handing off a baton. At exactly $t = t_1$, Phase 1 (cruising) ends, and Phase 2 (braking) starts. The position and velocity cannot jump instantly (that would require infinite force!). So, Phase 1 hands over its current position $v_0 t_1$ and speed $v_0$ to Phase 2. These become the absolute anchor points of the next phase.

Algorithms & Integration Mechanics

The computational steps to solve or simulate this multi-phase transition

Analytical Physics Calculus Algorithm

  1. 1
    Define the Domains and Bounds Break down the problem timeline into non-overlapping domains: $D_1 = [0, t_1]$ and $D_2 = [t_1, t_2]$. Write down constant parameters ($v_0, c, t_1$).
  2. 2
    Solve Phase 1 Equations ($t \in D_1$) Integrate $a(t) = 0$ with $v(0) = v_0$ to find $v_1(t) = v_0$. Integrate $v_1(t)$ with $x(0) = 0$ to get $x_1(t) = v_0 t$.
  3. 3
    Calculate Phase 1 Handover Limits Compute the state variables at the transition boundary:
    v1_end = v_0;
    x1_end = v_0 * t_1;
  4. 4
    Solve Phase 2 with Phase Offset Integration ($t \in D_2$) Use the substitution variable $u = (t' - t_1)$ to integrate $a(t) = -cu$. This simplifies the definite integral and cleanly matches initial conditions at the transition boundary: $$v(t) = v_1\_end + \int_{t_1}^t -c(t' - t_1)dt' = v_0 - \frac{1}{2}c(t-t_1)^2$$
  5. 5
    Find Total Stopping Point ($t_2$) Set the velocity function in Phase 2 to $0$: $$v(t_2) = 0 \implies v_0 - \frac{1}{2}c(t_2-t_1)^2 = 0 \implies t_2 = t_1 + \sqrt{\frac{2v_0}{c}}$$

Computational Simulation Loop

Our interactive simulator uses high-fidelity numerical integrations and analytical formula evaluation. The render update function processes each frame as follows:

// Frame Update Loop (Executed at 60 FPS)

function updateState(t, v0, t1, c) {

const delta_stop = Math.sqrt((2 * v0) / c);

const t2 = t1 + delta_stop;

// Clamp time simulation to stopped state

t = Math.min(t, t2);


if (t <= t1) {

// Phase 1: Constant Velocity

current_a = 0;

current_v = v0;

current_x = v0 * t;

} else {

// Phase 2: Variable Deceleration

let dt = t - t1;

current_a = -c * dt;

current_v = v0 - 0.5 * c * dt * dt;

current_x = v0 * t1 + v0 * dt - (1/6) * c * dt * dt * dt;

}

return { x: current_x, v: current_v, a: current_a, t2: t2 };

}

Recall Card 1

Why do we use $x_2(t_1) = v_0 t_1$ as our position constant in Phase 2?

Tap to flip
Explanation

For physical continuity. The car cannot magically teleport instantly. The final position of Phase 1 ($x(t_1) = v_0 t_1$) must seamlessly match the start position of Phase 2.

Continuous Boundary Constraint
Recall Card 2

What is the physical significance of the constant $c$ in the acceleration equation $a(t) = -c(t-t_1)$?

Tap to flip
Explanation

$c$ represents the jerk rate, which is the rate of change of acceleration over time ($\frac{da}{dt} = -c$). It measures how aggressively the braking force escalates.

Unit: m/s³ (Jerk constant)
Recall Card 3

How does stopping time $t_2$ scale if you double the initial cruising speed $v_0$?

Tap to flip
Explanation

The braking duration $(t_2 - t_1)$ is $\sqrt{2v_0/c}$. Therefore, if you double $v_0$, the braking time scales by a factor of $\sqrt{2} \approx 1.414$, not by double.

Proportionality: $(t_2 - t_1) \propto \sqrt{v_0}$
