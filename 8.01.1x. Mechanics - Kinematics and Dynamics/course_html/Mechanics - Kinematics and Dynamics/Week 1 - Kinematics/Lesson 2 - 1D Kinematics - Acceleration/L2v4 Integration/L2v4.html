Blackboard Highlight: Why Use the Prime Notation $t'$?

As explained at the end of the lecture slide, you will often see equations written as: $$v(t) = v_0 + \int_{t'=t_0}^{t'=t} a(t') \, dt'$$ What does this mean? Why not write just $a(t) dt$?

The Running variable: $t'$ (Dummy variable)

This is a placeholder variable. As we add the rectangles from our Riemann sum, the index $t'$ runs through every tiny incremental slice between $t_0$ and the end target $t$.

The Target Limit: $t$ (Specific Later Time)

This is the absolute stopping time boundary where we want to know the resulting final velocity or position. Using the same symbol $t$ for both the running step and the endpoint limit would create fatal mathematical ambiguity.

Kinematic & Integral Calculus Formula Handbook

Core derivations and calculus theorems discussed in the lecture presentations.

Fundamental Definite Integral

Defines the precise area under a curve bounded from point $a$ to point $b$.

$$\int_{x=a}^{x=b} f(x) \, dx = G(b) - G(a)$$

Where $G(x)$ is the antiderivative of $f(x)$, satisfying $dG/dx = f(x)$.

Constant Acceleration Integrals

When $a(t) = a_0$ is constant over a time interval $\Delta t = t_1 - t_0$:

$$\Delta v = a_0 \Delta t \quad \implies \quad v(t_1) = v(t_0) + a_0(t_1 - t_0)$$

Continuous Kinetic Integration Path

By continuous accumulation, we determine instantaneous velocity and position functions:

$$v(t) = v(0) + \int_{0}^{t} a(t') \, dt'$$
$$x(t) = x(0) + \int_{0}^{t} v(t') \, dt'$$

Notice the double integration pathway required to move from forces/acceleration directly back to position space.

Indefinite Integration

Solves the inverse-derivative problem resulting in a family of curves with an arbitrary constant $C$:

$$\int f(x) \, dx = G(x) + C$$

In kinematic equations, the arbitrary constant is uniquely determined by setting boundary/initial conditions like $v(t_0) = v_0$.
